## 게시 전 확인

- 운영 서버에 분석 결과 30일 보관 및 삭제 기능 배포·검증
- 실제 호스팅 서비스의 백업 보관 기간 및 삭제 후 복구 방지 절차 확인
- 외부 서비스 데이터 처리 설정 확인 후 문서 확정 및 시행일 기재
- docs/privacy/index.html의 초안 표시와 noindex 제거
- Settings → Pages → Source: GitHub Actions 선택
- Actions → Publish privacy page → Run workflow 실행
